# Audit — accuracy, formatting and efficiency of the visuals (2026-10-27)

Scope: what ends up on screen and in the mix — charts, plots, equations,
diagrams, media, narration — plus the tools used to check them. Earlier audits:
[CODE_AUDIT.md](CODE_AUDIT.md) (code structure, 2026-10-20) and
[AUDIT.md](AUDIT.md) (the moviepy version).

Method: stress projects rendered to stills with the new `python -m studio.render.stills`
(exact export frames), read against the source maths and data, then fixed and
locked with tests (`frontend/tests/accuracy.test.mjs`).

Status: **fixed** (in this pass), **new** (feature added in this pass), **planned** (next, not built yet), **open** (left, with reason).

## 1. Accuracy — the picture said something the data did not

| # | Where | Problem | Status |
|---|---|---|---|
| A1 | `graph` bar labels | Count-up labels used `Math.round`: 0.82 showed as **1**, 1.5 as **2**, 0.07 as **0**. Any chart of rates, probabilities or decimals misreported its data. | fixed — labels keep the data's own precision (`decimalsOf`, `fmtNum`) |
| A2 | `graph` negatives | The axis ran from 0 up only; a negative bar was not drawn at all, but its label still appeared below the chart. | fixed — the axis spans min…max through zero, bars grow up or down from an ink zero line |
| A3 | `plot` asymptotes | `tan x`, `sec x`, `1/(x−a)`: consecutive samples on either side of a pole were joined, drawing false vertical lines. | fixed — a jump across the whole window whose midpoint is not between its ends breaks the line |
| A4 | `plot` sampling | A fixed 240 samples, so fast curves (sin 20x over a wide range) aliased. | fixed — about one sample per 1.5 px of plot width |
| A5 | `plot` scale | No way to get one unit the same length on both axes, so circles, slopes and angles were distorted. | fixed — `aspect: equal` |
| A6 | `plot` markers | Drop lines ran from the point to the bottom edge of the panel, not to the x-axis. | fixed |
| A7 | `plot` labels | Tick labels were `round(v·100)/100` (0.005 steps read as 0.01, ASCII hyphen as minus); no axis names. | fixed — tick-precision labels, true minus, `x_label`/`y_label` |
| A8 | `math` accents | `\hat{}` only knew six letters; `\hat{b}` or `\hat{\beta}` **silently dropped the hat**. | fixed — accents (`\hat \bar \vec \tilde \dot \ddot \overline`) are drawn over any base |
| A9 | `math` signs | A sign at the start of a reveal term was always treated as unary, so `… | + b` was squeezed to `+b`. | fixed — unary only after nothing, an operator or an opening bracket, across terms |
| A10 | `math` brackets | Parentheses never grew, so `(a/b)²` had tiny brackets beside a two-storey fraction; superscripts sat at a fixed height and collided with tall bases. | fixed — automatic and `\left…\right` fences; script shifts clear the base |
| A11 | `math` coverage | No `\sqrt`, integrals, limits, matrices, `\binom`, cases, norms, sets/logic symbols, `\mathbb`. `|` could not be written at all (it is the term splitter). | fixed — new `renderer/tex.js`; `\abs{}` `\norm{}` and `|` inside braces |
| A12 | `math` `\text{}` | Spaces inside `\text{if x}` were lost. | fixed — read raw |

## 2. Formatting

| # | Where | Problem | Status |
|---|---|---|---|
| F1 | `graph` | Category labels overlapped when there were many bars. | fixed — shrink to fit their slot |
| F2 | `graph` line mode | No value labels on the points. | fixed |
| F3 | `plot` | Curve labels could leave the plot area (e.g. a curve ending below the window). | fixed — clamped inside |
| F4 | `math` | Function names had no thin space (`sin x`), commas no space after, italic `f(` overlapped its bracket in a serif face. | fixed — TeX-like spacing classes |
| F5 | `math` | Only the body sans was available; printed maths reads better in a maths serif. | fixed — `face: serif` (Cambria Math) |
| F6 | `math-code-demo.json` | The sigmoid caption runs into the plot panel. Nothing caught it. | fixed — demo layout; and the critique now reports cross-clip collisions (L1) |

## 3. Quality gate and tools

| # | Where | Problem | Status |
|---|---|---|---|
| L1 | `studio/critique` | Only safe-area and overflow were checked; a text box of one clip running into another clip's box passed. | fixed — `layout.collisions` (text wholly inside another clip's box counts as an overlay, not a collision); layout score × 0.85 when any |
| L2 | dev loop | No way to look at a few exact frames without a range render. | new — `python -m studio.render.stills project.json --at 2.5,6` |
| L3 | tests | No regression tests for the numbers on screen. | fixed — `frontend/tests/accuracy.test.mjs` |

## 4. Efficiency

| # | Where | Problem | Status |
|---|---|---|---|
| E1 | `math` layout | `measure()` was re-run recursively inside every draw and every frame re-parsed the source: O(n²) per frame. | fixed — parse memoized by source, measure memoized per node, size and face |
| E2 | render capture | Every frame is a PNG screenshot over CDP (PNG encode in Chromium, decode in ffmpeg); this dominates render time (~19 fps at 1080p30 with 4 workers). | open — try CDP `Page.captureScreenshot` with `optimizeForSpeed`, keeping output lossless; measure before switching |
| E3 | `sketch` pack | ~0.6 s a frame (blur on fading elements, whole page redrawn). | open — owned by the sketch-pack work (see `styles/sketch/README.md`) |

## 5. Media, narration and sources

| # | Where | Problem | Status |
|---|---|---|---|
| M1 | audio | No voice-over: narration only as an uploaded file. | planned — `studio/voice` (Windows speech, an auditorium room, word timings) |
| M2 | audio | Music ducking under narration is a flat −9 dB for the whole audio clip, pauses included; sound effects are not ducked at all. | planned — duck the bed and effects only while speech is present |
| M3 | captions | No subtitle track tied to the audio. | planned — `captions` component (word-timed, active word highlighted) and `.srt` export |
| M4 | `image` | Zoom drift was linear and could not pan, so montages looked static. | planned — `pan_x/pan_y/zoom_to` Ken Burns move on a soft ease |
| M5 | attribution | Commons photos are CC BY / BY-SA but nothing put the credit on screen. | planned — the narrated builder adds a credits card from `assets/MANIFEST.json` |
| M6 | sources | Nothing checked that quoted or narrated facts were in the source (the failure seen in the IKC assessment). | planned — `studio/wiki`: pinned revision, verbatim quote check, per-sentence support check, report |

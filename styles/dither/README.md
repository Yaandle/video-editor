# Dithering

The picture is reduced to 2–4 inks by **ordered dither** at a fixed native
resolution: the frame divided by `pixel` (3 → 640×360 at 1080p). The core then
upscales it by an exact integer with nearest-neighbour sampling, so every dither
pixel is a crisp k×k block and every output pixel is one of the chosen inks.

## Pattern stability

The threshold is a Bayer matrix (2×2, 4×4, 8×8) computed from each native
pixel's integer coordinates, or a 64×64 **blue-noise** map
(`assets/bluenoise64.png`, generated by `make_bluenoise.py` with
void-and-cluster from a fixed seed). Both are anchored to the native pixel grid,
so a held frame is bit-identical to the next and the pattern cannot crawl or
swim. The critique checks this: `max_static_diff` must stay under 0.5/255,
integer blocks must be uniform, and all pixels must be exact palette colours.

**Error diffusion** (`method: error-diffusion`, Floyd–Steinberg in RGB) is
offered **for stills only**: an image clip with no enter/exit, motion path or
drift. On anything that moves, the error field changes every frame and
shimmers, so those clips fall back to the ordered matrix.

## Choosing inks

Each pixel's colour is projected onto the nearest *segment* between two inks
and the threshold picks an end. So:

- grey edges and greyscale photos dither ink↔paper and never pass through orange;
- warm tones reach for orange;
- a flat fill that already is an ink passes through as exactly that ink.

| `inks` | |
|---|---|
| `mono` | ink + paper (1-bit) |
| `duo` | cobalt + paper |
| `tri` | ink, orange, paper |
| `quad` | ink, cobalt, orange, paper |
| `acid` | ink + lime |

## Motion

- `reveal: develop`: the threshold bias springs (`soft`) from blank paper to
  the picture over `reveal_beats`.
- `level_punch`: contrast jumps on every bar downbeat and springs back
  (`snappy`), timed with the bed's crunch. The pattern itself never moves.

## Use it

Set it as the project style to dither the whole frame, or on single clips
(their layer is dithered with dithered alpha, `ground: clear`). In a dithered
project, a clip styled `neo-brutal` opts out and draws on top. Use this for
credits and anything that must stay smooth.

## Sound

`sound.py` runs everything through a bit crusher (few-bit amplitude,
sample-and-hold): blips, noise bursts, a crunchy impact, a 12-step sweep
into cuts, and the `bitcrush` bed (crushed kick, noise snare, square-wave
arpeggio over A–F–C–G).

## Known limits

- Small body text gets coarse at `pixel` 4–6. Keep type at `h2` or larger, or
  opt it out.
- The ink choice is per pixel in RGB, so very saturated photos with colours far
  from every ink still snap to the nearest pair. Pick the ink set to suit the
  content.
